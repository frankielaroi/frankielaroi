## Current Work at Kofa

35+ stories, tasks and fixes in my first two months across four products: operations dashboard, network platform, fleet-partner portal and the Flutter rider app.

- **Real-time alerts:** notification inbox plus web push (service worker) so ops staff see at-risk stations and battery-movement requests even with the app closed
- **Manual slot unlock:** riders on redistribution trips can finish a pickup or drop-off when a station slot faults
- **Slot activity log:** search and type/date filters so technicians and support diagnose a faulty slot in one view
- **Fleet map:** live moving, parked and immobilised bike counts for fleet partners, plus data-accuracy fixes across platforms
